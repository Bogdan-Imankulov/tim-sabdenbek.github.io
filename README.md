# tim-sabdenbek.us — athlete portfolio

Static one-page portfolio for Temirkhan Sabdenbek (Modern Pentathlon, Team USA).
No build step, no frameworks — plain HTML + CSS + a little vanilla JS + Bootstrap 5 from CDN.
Upload the folder to any cheap static hosting and it works.

## Structure

```
index.html          — the whole page (all sections live here)
css/style.css       — all custom styles, organized by section with comments
js/main.js          — small helpers: navbar on scroll, scroll-reveal, footer year
assets/img/         — optimized photos used by the site (~100–350 KB each)
photos/             — ORIGINAL full-size photos (not used by the site; safe to
                      remove from the server to save space, keep a backup!)
*.txt               — original source texts the content was written from
```

## How to edit content

Everything visible is in `index.html`, in clearly commented sections:

- **Hero (top block)** — name, intro text, stats, contact buttons.
  Search for `HERO`.
- **Achievement cards** — search for `JOURNEY / ACHIEVEMENTS GRID`.
  Each card is one `<article>...</article>` block. To add a new card,
  copy an existing block and change:
  1. the image `src` (put a new photo in `assets/img/`),
  2. the title / texts,
  3. the `id` used by the collapse (`more-XXX` must match in
     `data-bs-target="#more-XXX"` and `id="more-XXX"` and `aria-controls`).
- **Gallery (slider)** — search for `GALLERY`. Each photo is one
  `<div class="carousel-item">` block — copy one to add a photo.
  Indicator dots appear automatically (generated by `js/main.js`),
  and clicking a photo opens it full-size in the lightbox.
- **Contacts / footer** — search for `CONTACT / FOOTER`.

## How to change colors / fonts

Open `css/style.css` — the palette is defined once at the top in `:root`
(`--navy`, `--red`, `--white`...). Change a variable and the whole site updates.

Style convention: no shorthand CSS properties — everything is written in
longhand form (`border-top-width`, `padding-left`, `background-image`, ...),
one property per line. Please keep new styles in the same format.

## Adding photos

1. Resize to max ~1600 px on the long side and compress (e.g. squoosh.app),
   aim for under ~350 KB per photo.
2. Put the file in `assets/img/` with a descriptive kebab-case name
   (`race-paris-2027.jpg`), and reference it from `index.html`.
3. Keep the original in `photos/` (or elsewhere) as a backup.

## Animations

- Hero entrance: CSS keyframes (`.anim-fade-up` + `.delay-*` in style.css).
- Sections fade in on scroll: add class `reveal` to any element — `js/main.js`
  picks it up automatically.
- Users with "reduced motion" OS setting get a static page (accessibility).

## Deployment

It's a static site: upload `index.html`, `css/`, `js/`, `assets/` to the
hosting web root (via FTP / hosting file manager). Nothing to install or build.
`photos/` and `*.txt` do not need to be uploaded.
